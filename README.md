## Description:

A repository documenting my progress, findings, and lessons learned while completing TryHackMe challenges, along with my efforts to improve my write-up skills. Some of the rooms in this writeup are comprised of previous writeup from over the year before June of this repository. I previously did short-form writeups on a google doc before converting to github to make my work more transparant.


## Config:

Some TryHackMe labs will require that you connect to their lab machine via your own machine. TryHackMe offers two ways to connect to their labs.
1. Using their own "attackbox" web-based machines that is easy to access however you only get access to their machines 60 min/day.
2. Using your own operating system and connecting into tryhackme's network through openvpn.
